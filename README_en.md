#### This project is based on Jialichuang ESP32S3N8R8 development board
Advantages
1. A dedicated gyroscope-to-USB-HID thread on an independent CPU core
2. Hardware SPI high-speed gyroscope data reading

## Notes
Battery power is optional; the battery components need not be soldered if battery power is not required.
The laser diode used in this equipment has a voltage of 3V
## Features
- ✅Point-and-click air mouse
- ✅OLED presentation prompts
- ✅Laser pointer
- ✅Telescopic wand
- ✅Bluetooth USB HID
- ✅Adjustable DPI

If you encounter any problems, please submit issues to me


## Project parameters

* This design uses ESP32S3 main control, high-performance dual-core and low-latency response;
* Uses an MPU6050 gyroscope for air mouse functionality;
* Uses an SH1106 OLED to display presentation prompts;
* This design uses laser diodes for laser pointers;
* This design uses a replaceable antenna to serve as a telescopic rod;
